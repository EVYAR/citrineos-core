## Runtime acceptance findings

OCPI active server builds Awilix container, registers all nine module tokens and initializes/subscribes DtoRouter. Notification migrations are in `apps/ocpi-server/db/migrations`; files are not edited. PostgreSQL notification ingestion, RabbitMQ delivery, partner headers and callbacks require actual isolated execution.

Stop-session query previously scoped only by country/party and active flag. Added exact numeric tenantId and TenantPartner.id/tenantId predicates; missing numeric context fails without a GraphQL lookup. Query variable interface and test assertions follow the actual document. No wire contract or protocol schema changed.

Sessions/CDRs query totalCost, numeric stationId and station relationship, but mappers still index contexts by OCPP transactionId. Same transactionId on two stations may collide even within one tenant. Wire Session.id uses transactionId; changing it requires partner migration/command compatibility decisions, not a silent port. Notification and owner queries now carry partition createdAt and tenantId. New cost helpers include energy/time/fixed pricing, but current mappers recalculate using tariff rather than proving canonical finalCost provenance/currency/VAT. This is inherited contractual-pricing coverage for issue 430, not authority to export retail benefits, redesign tariffs or reinterpret totals.

No unit/build/container acceptance is claimed. See deployment runbook and control result/window request for actual checks and outstanding gates.

## Parent decisions applied

Wire/product/session IDs remain unchanged. Notification fetch and push owner queries now require tenantId plus (id,createdAt), reject missing/ambiguous matches, and never guess Transactions[0]. New notification migration retains createdAt/stationId on UPDATE. Batch session maps reject duplicate wire session IDs rather than mixing station contexts; cross-page/stored collisions require later compatibility evidence. UI detail fetch reads up to two matches and refuses ambiguous results; toggle mutation carries the selected createdAt internally without changing its public URL.

Station deletion now follows existing disabled/title pattern for any transaction history, absent history evidence or OCPP history; handler also guards the action. No history cascade is introduced. Connector/EVSE delete controls remain absent. Concurrent DB deletion/retention authorization remains a server-side parent acceptance concern.

Pricing clarified by parent: preserve upstream CPO/eMSP contractual mapping, distinct from private local retail benefits. No evidence of standalone EVYAR authoritative partner-cost behavior was found, so no Core.totalCost substitution/net-gross inference is ported. Inherited mapping limitations belong to platform issue 430. The two architecture pricing audits were read; proposed later financial integration is not implemented here.
